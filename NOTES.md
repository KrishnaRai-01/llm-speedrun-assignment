The final configuration uses a 512-vocabulary BPE tokenizer, AdamW with cosine decay and 200 warmup steps, RMSNorm, SwiGLU, and tied weights. Under the 2,000,000-parameter budget, this model fits at 1,926,592 parameters, which leaves a small but useful margin for safe grading while still allowing 4 layers of 192-dimensional hidden state with 6 heads. The byte-level fallback in the tokenizer preserves lossless UTF-8 handling, so the model can still score arbitrary text correctly even when merges do not cover a sequence. AdamW with warmup and cosine decay uses the limited 2000-step budget more effectively than a constant learning rate by stabilizing early updates and then concentrating learning near the end of training. RMSNorm and SwiGLU reduce optimization friction and improve capacity per parameter compared with a standard LayerNorm plus GELU stack. Weight tying removes one full vocabulary projection matrix from the untied parameter budget, which is what makes the 4-layer configuration feasible. CPU-only execution further favors this compact design because it minimizes memory traffic and keeps the training and evaluation path simple. The result is the highest practical learning signal per step within the assignment constraints.
